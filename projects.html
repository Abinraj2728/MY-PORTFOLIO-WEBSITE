Smart Home IoT Prototype

A virtual IoT prototype simulating a smart home environment, created for a Robotics subject. Features automatic light control with a PIR motion sensor, temperature-based fan control (DHT22, 30°C threshold), and remote control simulation via serial commands. Built with Arduino on Wokwi.

Key Features

  • Automatic lighting: PIR motion sensor triggers LED when movement detected
  • Temperature-based fan control: DHT22 sensor reads temperature; fan activates above 30°C threshold
  • Remote control: Serial commands simulate remote operation and monitoring
  • Virtual prototyping: Entire system built and tested on Wokwi simulator

Technologies Used

Arduino IoT Wokwi Simulator PIR Sensor DHT22 C++ (Arduino) Serial Communication

What I Learned

  • Sensor integration and reading analog/digital inputs
  • Conditional logic for automation (if temperature > threshold, activate output)
  • Arduino programming and hardware simulation
  • Building complete IoT workflows from sensor to actuator

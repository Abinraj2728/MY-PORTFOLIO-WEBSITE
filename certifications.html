Applied Assignment — Telecom CDR Analytics Platform

As part of the IoT and Cloud Computing course, I completed a full written report designing a cloud-native AWS architecture for a regional telecom operator processing 50 million Call Detail Records (CDRs) per day.

  • Ingestion: AWS Direct Connect, Amazon S3 with WORM Object Lock
  • Streaming: Amazon Kinesis Data Streams + AWS Lambda enrichment
  • Data Lake: Amazon S3 with Parquet format, partitioned by date
  • Warehouse: Amazon Redshift (Reserved Nodes) + Redshift Spectrum
  • Ad-hoc Queries: Amazon Athena on S3 with AWS Glue Catalog
  • Visualization: Amazon QuickSight dashboards
  • Security: KMS encryption, GuardDuty, Macie, CloudTrail (GDPR Art. 33)
  • Well-Architected alignment: Security, Reliability, Performance, Cost

Key Skills Gained

  • Cloud architecture design using AWS best practices
  • Cost optimisation with Reserved vs On-Demand pricing
  • Shared Responsibility Model applied to sensitive data (CDRs)
  • Well-Architected Framework review of production workloads
  • Real-world IoT/Telecom scenario analysis and design

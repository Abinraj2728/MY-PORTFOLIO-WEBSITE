What is The Odin Project?

The Odin Project is a free, open-source curriculum that teaches full-stack web development. Unlike video courses, it focuses on project-based learning — you build real applications as you learn.

I chose The Odin Project because it emphasizes practical skills over tutorials. Every concept comes with a project that forces you to apply what you've learned.

Curriculum Tracks

  • Foundations: HTML, CSS, JavaScript basics, Git, and developer tools
  • Full Stack JavaScript: Advanced JS, React, Node.js, Express, MongoDB
  • Full Stack Ruby on Rails: Alternative track (not taken)

Skills Being Developed

  • Semantic HTML & modern CSS (Flexbox, Grid)
  • JavaScript (ES6+), DOM manipulation, async/await
  • Git & GitHub workflows
  • React, Node.js, Express, databases
  • Testing, debugging, and clean code practices

Why It Matters

  • Portfolio-ready projects — every lesson produces a real app
  • Industry-relevant — teaches what actual developers use
  • Community-driven — active Discord and open-source
  • Free forever — no paywalls

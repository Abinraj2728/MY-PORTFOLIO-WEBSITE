MDN HTML Reference Page

A list of essential HTML tags from MDN Web Docs, with my own explanations.

Category Tag My Explanation
Structure <!DOCTYPE html> Declares that the document is an HTML5 file. It must be the very first line.
Structure <html> The root element that wraps all the content on the entire page.
Structure <head> Contains meta-information about the document, like the title and CSS links. It doesn't show on the page.
Structure <body> Contains all the visible content of the page, like text, images, and buttons.
Metadata <title> Sets the title of the page, which appears in the browser tab.
Metadata <meta> Provides metadata like character set (`UTF-8`), page description, or viewport settings for mobile.
Metadata <link> Links external resources to the document, most commonly used for connecting CSS stylesheets.
Text <h1> to <h6> Heading tags. `<h1>` is the main title, and `<h6>` is the smallest sub-heading.
Text <p> Defines a paragraph of text. Browsers automatically add some space above and below it.
Text <br> Inserts a single line break (like pressing Enter). It is an empty tag, so it has no closing tag.
Text <hr> Creates a horizontal rule (a line) to separate content.
Text <strong> Marks text as important, usually rendering it as bold.
Text <em> Marks text with emphasis, usually rendering it as italic.
Lists <ul> Creates an Unordered List (a bulleted list).
Lists <ol> Creates an Ordered List (a numbered list).
Lists <li> Defines a List Item. It must be used inside a `<ul>` or `<ol>`.
Media <a> Anchor tag. Creates a hyperlink to another page or section using the `href` attribute.
Media <img> Embeds an image. It requires the `src` (file path) and `alt` (description) attributes.
Media <video> Embeds a video player. You can add the `controls` attribute to show play/pause buttons.
Media <audio> Embeds sound content, like music or podcasts.
Containers <div> A block-level container used to group elements for styling with CSS.
Containers <span> An inline container used to style a specific part of text without breaking the line.
Containers <header> Represents introductory content, usually containing the logo and navigation.
Containers <footer> Represents the footer of a page, typically containing copyright or contact info.
Containers <nav> Defines a set of navigation links (like a menu bar).
Forms <form> Creates an interactive form to collect user input.
Forms <input> Creates an input field. The `type` attribute changes it to text, email, password, checkbox, etc.
Forms <button> Creates a clickable button.
Forms <label> Defines a label for an input element to improve accessibility.
Forms <textarea> Creates a multi-line text input field (good for messages).
Forms <select> Creates a drop-down list. It contains `<option>` tags inside.
Tables <table> The container for all table content.
Tables <tr> Defines a table row.
Tables <th> Defines a table header cell (usually bold and centered).
Tables <td> Defines a standard table data cell.

10 HTML Tags with Explanation

<h1>

Main heading of the page. Used once for the biggest title.

<h1>Welcome</h1>

<p>

Paragraph tag. Used to write blocks of text.

<p>Hello world</p>

<a>

Anchor tag. Creates a clickable link using the href attribute.

<a href="https://example.com">Visit</a>

<img>

Image tag. Shows a picture. Needs src and alt attributes.

<img src="pic.jpg" alt="photo">

<ul>

Unordered list. Creates a bulleted list.

<ul><li>Item</li></ul>

<ol>

Ordered list. Creates a numbered list.

<ol><li>First</li></ol>

<li>

List item. Used inside ul or ol for each list entry.

<li>My item</li>

<div>

Division. A container used to group content and apply styles.

<div>Content</div>

<span>

Inline container. Used to style a small part of text.

<span style="color:red">red text</span>

<button>

Button tag. Creates a clickable button.

<button>Click Me</button>

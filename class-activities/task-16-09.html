10 HTML Tags with Explanation

<h1>

Main heading of the page. Used once for the biggest title.

<h1>Welcome</h1>

<p>

Paragraph tag. Used for blocks of text.

<p>This is a paragraph.</p>

<a>

Anchor tag. Creates a hyperlink to another page.

<a href="https://example.com">Click here</a>

<img>

Image tag. Embeds an image into the page.

<img src="photo.jpg" alt="My Photo">

<ul>

Unordered list. Creates a bulleted list.

<ul><li>Item</li></ul>

<ol>

Ordered list. Creates a numbered list.

<ol><li>First</li></ol>

<li>

List item. Used inside ul or ol for each entry.

<li>My item</li>

<div>

Division. A container used to group content.

<div>Content</div>

<span>

Inline container. Used to style a small part of text.

<span style="color:red">red text</span>

<button>

Button tag. Creates a clickable button.

<button>Click Me!</button>
